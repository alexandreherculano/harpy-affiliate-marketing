> **From research to published video – with a single approval.**

Harpy is an end-to-end affiliate marketing automation tool. It transforms your AI agent into a complete content creation and distribution engine for TikTok and Instagram Shorts. Just pick a niche, approve the generated video, and Harpy handles the rest.

---

## ✨ Features

| Feature | Description |
| :--- | :--- |
| 🔍 **Trend Research** | Scans TikTok, YouTube, and Reddit to find high-commission, low-competition products. |
| 📝 **Script Generation** | Creates 15–30s short-form scripts with hooks, problem-solution, and CTA. |
| 🎬 **Auto Video Rendering** | Downloads stock clips, generates AI voiceover, adds captions, and syncs cuts automatically – **zero manual editing**. |
| 📤 **Multi-Platform Publishing** | Posts to TikTok and Instagram via official APIs (or fallback to copy-paste mode). |
| 🤖 **Human-in-the-Loop** | Previews every video and caption before posting – approve or reject with one keystroke. |
| 📊 **Performance Analytics** | Tracks views, clicks, and conversions to refine future content automatically. |
